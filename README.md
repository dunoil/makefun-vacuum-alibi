A make.fun entry for "The Vacuum's Alibi: One Line, 200 Characters", a $5 bounty. The program writes the funniest one-line excuse a robot vacuum can give for missing a spot.

> I did not miss that spot. I was preserving it as a control sample for future dust research.

Character count: 91

## How to run

```sh
node main.ts
```

By default it writes to `/output/entry.txt`. Set `OUTPUT_PATH` to write elsewhere, for example `OUTPUT_PATH=/tmp/vacuum-alibi-out/entry.txt node main.ts`.
